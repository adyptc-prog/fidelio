Privacy Policy — Fidelio

Last updated: June 2026

Overview

Fidelio is a local-first application. It does not collect, store, or transmit any personal data to external servers.

Data collection

Fidelio collects no data. The application has no internet connectivity and requires no user account or registration.

Data storage

All data entered in the application (business profiles, customer records, loyalty cards) is stored exclusively on your device in a local database. This data never leaves your device unless you explicitly create a backup to a USB drive.

USB backup

If you use the backup feature, data is written to a USB drive you choose. This data remains under your full control at all times.

Permissions

  • Camera — used only to scan QR codes within the app.
  • NFC — used only for card-to-card communication within the app.

Third parties

Fidelio does not share data with any third parties. No analytics, no advertising, no tracking.
